# My New Project

Dự án thực hành tạo Repository mới trên GitHub và đồng bộ giữa Local Repository với Remote Repository.

## Các câu lệnh Git đã sử dụng

- `git init`: Khởi tạo một Git Repository mới trong thư mục hiện tại.
- `git remote add origin <repository-url>`: Liên kết Local Repository với Remote Repository trên GitHub và đặt tên remote là `origin`.
- `git add README.md`: Đưa file README.md vào vùng staging để chuẩn bị commit.
- `git commit -m "Add README.md file"`: Lưu lại thay đổi thành một commit kèm thông điệp mô tả.
- `git branch -M main`: Đổi tên nhánh hiện tại thành `main`.
- `git push -u origin main`: Đẩy các commit từ nhánh `main` ở máy lên Remote Repository và thiết lập liên kết upstream.
